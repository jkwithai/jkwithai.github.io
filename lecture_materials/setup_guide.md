# [교육 준비물] 노트북 사양 및 필수 프로그램 설치 가이드

원활한 강의 진행을 위해 교육 시작 전 아래 내용을 반드시 확인하고 준비해 주세요.

## 1. 노트북 최소 사양 (추천)
- **운영체제**: Windows 10 이상 또는 macOS (최신 버전 권장)
- **CPU**: Intel Core i5 / AMD Ryzen 5 이상
- **메모리(RAM)**: 8GB 이상 (16GB 권장)
- **저장공간**: 여유 공간 1GB 이상

## 2. 필수 설치 프로그램
강의 중 설치하는 데 시간이 소요될 수 있으므로 사전에 설치를 완료해 주세요.

1.  **Visual Studio Code (VS Code)**
    - 다운로드: [code.visualstudio.com](https://code.visualstudio.com/)
    - 설치 후 필수 확장 프로그램: `Python`, `Prettier`
2.  **Python 3.10 이상**
    - 다운로드: [python.org](https://www.python.org/downloads/)
    - **중요**: 설치 시 `Add Python to PATH` 옵션에 반드시 체크해 주세요.
3.  **Git**
    - 다운로드: [git-scm.com](https://git-scm.com/)
    - 설치 과정 중 기본 옵션으로 진행해 주세요.

## 3. 계정 준비
1.  **GitHub 계정 생성**
    - [github.com](https://github.com/)에 가입하고 이메일 인증까지 완료해 주세요.
2.  **인터넷 연결 환경**
    - 실시간 데이터 수집 및 배포를 위해 안정적인 Wi-Fi 환경이 필요합니다.
