# [강의 계획안] 나만의 AI 자동화 인사이트 대시보드 만들기

## 1. 강의 개요
- **강의명**: AI 비전공자를 위한 "6시간마다 자동 갱신되는 나만의 인사이트 대시보드" 구축하기
- **대상**: AI 자동화 및 코딩 입문자 (기초 지식 없어도 수강 가능)
- **강의 목표**: Python 크롤링, GitHub Actions 자동화, 그리고 세련된 웹 대시보드 제작의 전 과정을 실습하고 나만의 결과물을 배포한다.

## 2. 강의 커리큘럼 (총 4세션)

### [세션 1] 자동화의 첫걸음: 환경 구성 및 기본 개념 (1시간)
- AI 자동화란 무엇인가? (Scraping, Actions, Pages의 결합)
- GitHub 계정 생성 및 레포지토리(저장소) 설정
- VS Code 및 Python 환경 점검

### [세션 2] 데이터 수집하기: Python 크롤링 실습 (1.5시간)
- 네이버 경제 뉴스 텍스트 수집하기
- 기업마당(Bizinfo) 지원사업 데이터 필터링 (서울/경기 지역)
- Open-Meteo API를 활용한 날씨 정보 가져오기
- `collector.py` 구조 이해 및 데이터 저장(JSON)

### [세션 3] 눈에 띄는 대시보드 만들기: 프리미엄 웹 디자인 (1.5시간)
- 'Midnight Glass' 테마를 활용한 글래스모피즘(Glassmorphism) 구현
- HTML5/CSS3 기초: 카드형 레이아웃 및 반응형 그리드
- JavaScript를 활용한 실시간 데이터 렌더링

### [세션 4] 잠자는 동안에도 일하는 AI: GitHub Actions 배포 (1시간)
- GitHub Actions 워크플로우(`.yml`) 설정하기
- 6시간마다 자동으로 돌아가는 '나만의 수집기' 완성
- GitHub Pages를 통한 전 세계 무료 웹 배포

## 3. 결과물 예시
- **URL**: `https://[사용자ID].github.io`
- **기능**: 뉴스, 날씨, 지원사업, 마켓 지표(KOSPI 등)가 포함된 개인용 통합 대시보드
